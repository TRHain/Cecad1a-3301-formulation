# v0.66 — Do the frozen ΔK states form a sequential state machine?

## Question

v0.64 found a seven-state marginal ΔK mixture but failed held-out significance. This test freezes those seven states and asks a narrower question: does their inferred state path contain first-order sequential/Markov structure on held-out blocks?

Frozen states:

`[26, 1, 8, 4, 23, 21, 5]`

## Method

- Same exact section 0.11 target and solved-p57 shifted emission prior as v0.64.
- Each ciphertext first difference receives the maximum-posterior frozen state label.
- First-order transition matrix fitted only on alternating 100-transition training blocks.
- Evaluated on complementary held-out blocks against an iid state-frequency model.
- Null: 10,000 within-heldout-block state-order shuffles, preserving each block's exact state composition.

## Result

Held-out Markov minus iid log-likelihood improvement per symbol:

**-0.01023**

Empirical order-shuffle **p ≈ 0.446**.

Same-state adjacent rate:

- overall: **18.27%**
- held-out: **18.85%**

Decision: **NO_SEQUENTIAL_DELTAK_EVIDENCE**.

## Interpretation

The v0.64 seven-state residues do not behave like a useful first-order hidden state schedule. This substantially weakens the specific small-ΔK-alphabet branch. The broader state-machine hypothesis remains alive, but its state cannot be captured by these marginal cyclic-shift residues plus a first-order transition law.
