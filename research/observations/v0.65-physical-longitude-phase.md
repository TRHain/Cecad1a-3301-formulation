# v0.65 — Physical longitude as phase

## Question

If the 2012 physical-drop longitudes are treated literally as phase angles on a 360° circle, do they phase-lock unusually at predeclared Cicada-related harmonics?

Harmonics tested before looking at the result:

`13, 17, 29, 133, 167, 331, 761, 1033, 3301`

## Method

- Used the 14 exact 2012 coordinates already in the lab.
- Statistic: Rayleigh phase concentration `R = |mean(exp(i*n*longitude))|` for each harmonic n.
- Family statistic: maximum R across the nine predeclared harmonics.
- Null A: independent uniform longitudes.
- Null B: cluster-preserving model with the observed duplicate-city multiplicities (Paris 2, Seattle 3, Seoul 2, and seven singleton sites) plus small local jitter. This is more conservative because duplicated coordinates inflate phase concentration.

## Result

Observed R values:

- 13: 0.3552
- 17: 0.3989
- 29: 0.4599
- **133: 0.5430**
- 167: 0.2486
- 331: 0.2092
- 761: 0.1130
- 1033: 0.2857
- 3301: 0.2595

Best harmonic: **133**.

Family-corrected uniform-longitude p ≈ **0.116**.

Family-corrected cluster-preserving p ≈ **0.455**.

The single-harmonic cluster-null p for 133 is ≈ **0.081**, but this is not the family-corrected result and should not be promoted.

Decision: **NO_PHYSICAL_PHASE_EVIDENCE** for direct longitude phase-locking at these harmonics.

## Interpretation

This is still informative. The physical-frequency idea survives conceptually, but **direct longitude × Cicada-number phase locking is not supported**. If geography matters, it is more likely through ordered travel/bearing/distance/time-zone/electrical-state relationships or through a derived signal rather than absolute longitude alone.
