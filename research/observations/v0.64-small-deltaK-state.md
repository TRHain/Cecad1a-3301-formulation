# v0.64 — Small ΔK state alphabet

## Question

Can LP2 section 0.11's ciphertext first differences be explained by a small hidden alphabet of effective key-difference states, where each state emits a cyclic shift of a solved Liber Primus plaintext distribution?

## Method

- Target: exact section 0.11, 1,589 runes.
- Observable: `ΔC_i = C_i - C_(i-1) mod 29`.
- Plaintext prior: exact solved page 57 rune unigram distribution with +0.5 smoothing.
- Candidate hidden ΔK state is a residue `s in 0..28`; emission is the plaintext prior shifted by `s`.
- Greedy train-only state selection for K=1..8.
- Alternating 100-transition blocks used as train/test split.
- K selected using train likelihood plus a complexity penalty; held-out result compared with 120 label-permuted plaintext-prior controls under the same search burden.

## Result

Train-selected model used **7 states**:

`[26, 1, 8, 4, 23, 21, 5]`

Held-out negative log likelihood: **3.36603**.

Matched null empirical **p ≈ 0.2810**; null mean held-out NLL ≈ **3.37058**.

Decision: **NO_SMALL_DELTAK_STATE_EVIDENCE**.

The selected residues overlap several clue-derived modulo-29 sets, but this is descriptive only and not evidence after the held-out test. In particular, the candidate set overlaps Fibonacci residues at `[1,5,8,21,26]` and Page32 prime-value residues at `[4,5,21,23]`.

## Interpretation

A small marginal mixture of shifted plaintext distributions does not explain section 0.11 strongly enough. This does **not** rule out a small sequential state machine; the next ΔK attack should model state transitions explicitly rather than only the marginal state alphabet.
