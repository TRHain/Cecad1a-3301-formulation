# v0.83 — Red-Event State Transition Replication

## Verdict

**NO_RED_EVENT_REFLECTION_STATE_EVIDENCE**

The frozen `delta' = (-delta + 8) mod 29` rule did not replicate. Independent
discovery in section 0.6 favored identity on both eligible pages. Held-out
section 0.12 had a positive aggregate, but only page 49 was positive and none
of the three frozen null controls was significant. The held-out result is a
near miss, not evidence. No offset, transform, window, event, or statistic was
changed after protocol commit `d325484`.

Red was treated only as a binary image-derived structural channel. No
plaintext, language score, protocol number, or JPEG intensity value was used.

## Frozen primary test

For a boundary coordinate `k`, the test compares transition-value
distributions `delta[k-58..k-1]` and `delta[k..k+57]`, where
`delta_i = (r_(i+1)-r_i) mod 29`. Jensen–Shannon divergence is measured in
bits. Positive `JS_identity - JS_reflection` favors reflection.

Event-boundary scores are averaged within event, then page, then phase, so
pages with more red objects cannot dominate. The independent discovery phase
is section 0.6; section 0.12 is held out. Sections 0.5, 0.7, 0.8, 0.9, and
0.10 have red events only at edges lacking a complete ±58 window. Each
principal control uses 20,000 replicates:

1. matched non-red boundaries on the same pages;
2. randomized whole-event positions preserving page, section, count, and run
   length;
3. independent within-page rune permutations.

P-values are one-sided and Bonferroni-corrected across the three control
families. Promotion also requires positive effects on at least two pages in
both phases and byte-identical deterministic reproduction.

## Secondary descriptive structure

Among 37 unsolved events, 21 touch a page edge, 16 touch a section edge, 36
have an explicit sentence/paragraph/page/section boundary relationship, and
29 are punctuation events or explicitly punctuation-associated. These raw
counts confirm that red is strongly concentrated in visible textual structure;
no inferential preference test was predeclared, so no significance claim is
made.

Across the four independent discovery boundaries, the after-minus-before
adjacent-repeat rate is `+0.01293`; it is also `+0.01293` across the four
held-out boundaries, while historical section 0.11 is `-0.00172`. Other
descriptive changes do not retain direction: delta entropy is `+0.03173` in
discovery and `-0.08170` held out; directed-bigram entropy is `-0.02586` and
`+0.01724`; rare/forbidden-bigram rates likewise change direction. These
statistics cannot modify the primary verdict.
