# v0.67 — Event-reset long-carrier screen

Tested the frequency/modulation hypothesis on exact LP2 section 0.11 while freezing event boundaries from prior independent work.

## Family

Periods: `133, 167, 331, 761, 1033, 3301`.

Phase-reset schemes: none, page boundaries, red boundary, and the previously detected v0.53 statistical-regime boundaries. No new change points were fitted for this experiment.

## Result

Best model: **period 761 with phase reset at the red boundary**.

Normalized power: `0.0026826064`.

The no-reset period-761 model was almost identical (`0.0026564094`), so the red reset contributes very little.

A matched null shuffled rune values and reran the complete 4×6 model family for 5,000 replicates. Family-corrected empirical **p = 0.13937**.

Decision: **NO_EVENT_MODULATION_EVIDENCE**.

## Observation

761 continues to appear near the top of the predeclared frequency family, but it still does not survive corrected controls. This is retained as a descriptive recurrence only. Periods 1033 and 3301 were weaker. Because section 0.11 is 1,589 runes, 3301 remains a partial-cycle probe here.

## Next

Do not expand the frequency-number family. The next valid frequency test requires a canonical concatenation of all unsolved LP2 runes so that 3301 is observed over multiple cycles, or an independently specified modulation observable.
