# v0.72 — Reflection / inversion as hidden state

## Question
Could the cicada image's bilateral/reflection motif point to a cipher-state inversion rather than a literal page fold?

## Target
Liber Primus section 0.11, using the previously frozen v0.53 regime boundaries and the red boundary at section coordinate 1468.

## Method
For each adjacent regime pair, compare the distribution of ciphertext differences `ΔC` under two constrained transforms of the next regime:

- identity family: `r -> r + b (mod 29)`
- reflection family: `r -> -r + b (mod 29)`

The offset `b` is optimized within each family. Similarity is measured with Jensen-Shannon divergence. The family-level control shuffles transition values globally while preserving the fixed regime lengths and reruns the full comparison.

A second frozen test uses a 58-transition window on each side of the red boundary at 1468 and compares identity versus reflection using circular-shift controls.

## Results
Across adjacent regimes, reflection beat identity in 6 of 10 pairs, but the total reflection advantage was not significant:

- reflection advantage: `0.0102652379`
- shuffle p-value: **0.3304**
- 6/10 reflection wins: **p = 0.3598**

At the red boundary, reflection fit better than identity:

- identity JS: `0.1589233840`, best `b = 0`
- reflection JS: `0.1331154663`, best `b = 8`
- reflection advantage: `0.0258079178`
- circular-shift p-value: **0.0888**

## Decision
**NO_REFLECTION_STATE_EVIDENCE** at the predeclared 0.05 threshold.

The red-boundary result is a secondary lead only (`p ≈ 0.089`). It is interesting because the transform favored across that boundary is specifically an inversion `r -> -r + 8`, but it does not survive the significance threshold and must not be promoted to a cipher rule.

## Interpretation
This weakens the simplest version of “mirror = flip the transition law.” It does **not** eliminate reflection as a higher-level operation, particularly if inversion is triggered only by a subset of red objects, page types, or longer historical/state conditions. Any follow-up must freeze those triggers independently before testing.
