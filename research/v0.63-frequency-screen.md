# v0.63 — Frequency and ΔK Screen

## Frequency branch

Predeclared periods included 13, 17, 29, 133, 167, 331, 761, 1033, 3301 and Fibonacci periods through 987.

On exact LP2 section 0.11 (1,589 runes):

- rune-number signal: family-corrected p = 0.06993; period 761 was among the strongest candidates;
- equality/repeat signal: family-corrected p = 0.21379; 3301 was the strongest predeclared candidate;
- ciphertext-difference signal: family-corrected p = 0.57343.

Decision: **NO FREQUENCY EVIDENCE YET**.

Important limitation: section 0.11 is shorter than 3301 runes, so a 3301-period statistic there is a phase/trend probe, not observation of a complete cycle. The next valid test is full-LP2 spectral/phase analysis.

## ΔK branch

Coarse candidate effective-key-difference residue alphabets based on prime gaps, Fibonacci values, Page32 ordinals and Gematria primes all covered essentially all rough common-rune candidates. The test was therefore non-discriminating.

Decision: **COARSE ΔK CLASS SCREEN UNINFORMATIVE**.

Next ΔK work should infer a smaller state alphabet from transition constraints rather than start from broad clue-number residue sets.
