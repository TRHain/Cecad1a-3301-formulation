# v0.70 — Ciphertext center-fold symmetry

Inspired by the near-bilateral cicada artwork, this experiment tests whether LP2 section 0.11 behaves like an inkblot/fold object at the ciphertext level.

## Test

Section 0.11 contains 1,589 runes, giving 794 mirrored rune pairs around the midpoint. Three predeclared families were tested:

- literal mirror equality;
- a single additive mirror offset `k mod 29`;
- a full affine mirror `a*x+b mod 29`, `a != 0`.

Matched nulls permuted the reversed right half while preserving rune marginals and reran the same search family.

## Results

- Literal mirror: 32 / 794 matches = 4.03%, `p = 0.2092`.
- Best additive offset: `k = 27`, 41 / 794 matches = 5.16%, family-corrected `p = 0.2012`.
- Best affine mirror: `a = 2, b = 1`, 45 / 794 matches = 5.67%, family-corrected `p = 0.5599`.

A descriptive center-band scan found 6 literal matches in the 58 pairs nearest the midpoint (10.34%), the maximum window value for that width in this section. This was not independently predeclared and is therefore retained only as a follow-up observation, not evidence.

## Decision

**NO_SIMPLE_FOLD_CIPHER_EVIDENCE.**

The fold hypothesis survives only in more structured forms: page-level folds, red-event-defined folds, or image residual analysis using original archived bytes. The simple section-midpoint mirror family is rejected.
