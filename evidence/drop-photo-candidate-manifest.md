## Important filtering observation

Search results also return later fan/reconstruction material that resembles Cicada posters. One image found in the same search includes a 2019 date and Ottawa coordinates; it is **not accepted into the 2012/2013 evidence set**. This is exactly why provenance must precede image-statistics work.

## Next acquisition step

For every 2012/2013 location, locate the earliest surviving post/thread/archive containing the photograph, then record source timestamp, file dimensions, hash if bytes can be obtained, claimed location, and whether independent contemporary reports agree. Only after that should QR angle, cicada orientation, pole geometry, image compression, or environmental frequency hypotheses be tested.
